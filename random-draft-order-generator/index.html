Random Draft Order Generator

Randomize the draft order for your league, fantasy or game night.

How to Generate a Random Draft Order

Paste your team or player names into the box — the sample list is already loaded if you just want to try it — then press Generate Order. Every name is shuffled and printed back with its pick number, so who picks first is decided by chance instead of by whoever shouted loudest. Press Reset for a clean list and generate as many times as you like: it is free, needs no account and nothing you type is uploaded.

Where a Random Draft Order Generator Helps

  • Fantasy leagues — settle your draft order in seconds before the season starts, and re-run it when a manager joins late.
  • Classroom speaking order — decide who presents or answers first, so the same students are not always at the front of the queue.
  • Game nights — pick the playing order for a board game, a quiz round or a turn-based tournament.
  • Draft day on stream — share your screen and let the whole league watch the order come out, with nobody able to claim it was rigged.

Snake Draft, Speaking Order and More

The tool hands you one clean random sequence, which is exactly what a snake draft needs: read it top to bottom for round one, then reverse it for round two and keep alternating. The same list works as a speaking order, a queue for the next round of a tournament, a batting order or a rota for chores. If you also need to split those names into teams for the season, send them straight to the Random Group Generator; for a slower, more theatrical reveal in front of an audience, use the Wheel Spinner instead.

Running a Draft Day Everyone Trusts

Most arguments about draft order start with the method, not with the result. Generating the order in front of the league — or posting the finished list with its pick numbers before anyone opens a spreadsheet — removes that doubt completely. Everyone can see that the first name really did come out on top, and that nobody edited the list afterwards.

Keep the list you generated: it is your record for the season, and it tells you who is on the clock in every round. When a manager drops out or a new one joins late, re-run the generator with the updated names and you have a fresh order that is fair again, with no need to renegotiate the rules mid-season.

Pick Numbers, Rounds and Turn Order

Each line of the result is a pick number: line one picks first, line two picks second, and so on until the last manager is on the clock. How many rounds you need is up to you — most fantasy leagues run one pick per manager per round, while a board game or a quiz night usually only needs the top of the list. For a serpentine or snake draft, reverse the sequence in even rounds; for a straight draft, read it top to bottom every time.

Prefer to draw the numbers separately and match them to names afterwards? Use the Random Number Generator for that half of the job.

Frequently Asked Questions

How do I generate a random draft order?

Type teams or players separated by commas, click Generate, and the list is shuffled into a fair random draft order with pick numbers.

Is the draft order really random?

Yes. It uses a Fisher-Yates shuffle in your browser, so every order is equally likely.

Is this also a random order generator?

Yes. This is a random order generator built for draft picks — paste your names and it shuffles them into a fresh sequence. The same shuffle works for deciding speaking order, seating order, queue position or who goes first in a game.

Can I use this for a snake draft?

Yes. Read the shuffled order forwards for round one and backwards for round two — that gives you the classic snake or serpentine draft with no extra setup. Press Generate Order again whenever you want a fresh sequence for the next season.

How many names can I shuffle at once?

There is no fixed limit. The shuffle runs in your browser, so a full league, a class list or a few hundred names all work and the result is instant — longer lists just take one extra scroll to read through.

Do I need an app or an account?

No. The draft order generator is free, needs no sign-up and no download, and runs entirely in your browser on a desktop or a phone. Your list of names is never uploaded to a server.

Is the order the same every time I press Generate?

No. Every click reshuffles the names from scratch, so you get a new sequence each time — that is what makes it a draw rather than a fixed list. If you want the result to stay put, keep the list you generated and leave the button alone.

Can I draw a single name instead of the whole order?

Yes. If you only need one winner — who buys the coffee, who takes the penalty, who goes home with the prize — the Random Name Picker draws one name at a time with a claw machine animation. This page orders your whole list; that one picks from it.

How do I shuffle a list into a random order?

Paste the names or teams, press Generate Order, and the list comes back in a random order with a number beside each entry. Every press re-shuffles from scratch, so nothing about the previous sequence carries over.

Does shuffling change the list I pasted?

No. The page keeps your original text untouched and builds a separate shuffled sequence beside it, so clearing the result or reloading returns you to exactly what you typed in.
