    How to use this random name picker

    1. Paste your names into the box — one per line, or comma separated.
    2. Press Pick One: the claw machine shuffles your names, the claw drops, and one random winner is grabbed.
    3. Tick Remove winner after pick to draw without repeats — keep going until everyone has been picked once.
    4. Press Shuffle Order to get your entire list back in a fresh random order — handy as a random name order generator for presentations or turn-taking.

    Frequently Asked Questions

    How does a random name picker work?

    Type or paste your list of names, then press "Pick One". The picker draws one name at random using your browser's built-in randomizer. Everything runs locally in your browser — your names never leave your device.

    What is a claw machine name picker?

    It's a name picker styled like an arcade claw machine: the machine shuffles your names, the claw drops, and grabs one random winner. It makes classroom picks and giveaways more fun to watch.

    Can I shuffle names into a random order?

    Yes — press "Shuffle Order" and you get your full list back in a brand-new random order, like a random name order generator.

    Can I pick multiple names without repeats?

    Yes. Tick "Remove winner after pick" and each winner leaves the pool, so you can keep drawing until every name has been picked exactly once.

    Is this name picker free?

    Yes. This random name picker is 100% free, works on phones and desktops, and never requires a sign-up or download.

    Is a random name picker the same as a random name generator?

    They are close cousins. A random name generator usually invents or lists names — think characters or usernames — while this random name picker draws a winner from names you already have, such as a class list or giveaway entrants.
